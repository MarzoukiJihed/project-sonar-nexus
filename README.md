# Construction d'une Chaîne CI/CD Sécurisée

Projet DevOps — CI/CD
Classe : Mastère CCDAD – M1
Encadrant : Hedi MAGROUN 
# Objectif du projet
Ce projet vise à construire une chaîne CI/CD professionnelle intégrant 
- SonarQube (analyse qualité du code)
- Nexus Repository (gestion des artéfacts Maven)
- Jenkins (automatisation )
# Outils utilisés
- Java 21
- Maven/SPRING BOOT 
- Docker
- SonarQube
- Nexus Repository
- Git / GitHub
# Structure du projet
- LAB_SONARQUBE.md → Analyse qualité du code
- LAB_NEXUS.md → Gestion des artéfacts
- README.md → Vue globale du projet
- code source de projet

# Semaine 1 
Objectif :
- Installation des outils
- Tests indépendants
- Compréhension de SonarQube et Nexus

# Semaine 2 
- Intégration Jenkins
- Pipeline CI/CD complet
- Automatisation build → test → deploy

# Résultat attendu
- Code analysé automatiquement par SonarQube
- Artéfacts stockés dans Nexus
